# NeverEat — Official Web Pages

Landing page and official policies for NeverEat.

## Pages Included
- **`index.html`**: Landing page with product presentation, features, and FAQ.
- **`privacy.html`**: Privacy Policy.
- **`terms.html`**: Terms of Service.
- **`style.css`**: Shared styles, theme variables, and responsive layout.

## Deployment
This repository is formatted for easy deployment with:
- **GitHub Pages**: Set Source to `Deploy from a branch` -> `main` / `/(root)`.
- **Vercel / Cloudflare Pages / Netlify**: Connect repository with zero configuration needed.
